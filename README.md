##  О проекте
Система предназначена для удобного поиска, сдачи и аренды коммерческой недвижимости (офисов, складов, коворкингов). Приложение разделяет функционал на две ключевые роли: **Пользователь** и **Администратор**, предоставляя каждому адаптированный интерфейс для решения своих задач.

Проект реализует полный цикл CRUD-операций, работу с изображениями, безопасное хранение паролей (SHA1-хеширование),  динамическое переключение тем оформления и программное построение аналитических диаграмм.

## Средства разработки и технологии
* **Среда БД:** Microsoft SQL Server Management Studio 2021 (SSMS) — проектирование реляционной БД, настройка каскадного удаления (`ON DELETE CASCADE`), заполнение тестовыми данными.
* **Среда разработки:** Microsoft Visual Studio 2022
* **Платформа:** C# / .NET Framework (WPF - Windows Presentation Foundation)
* **Работа с документами:** Microsoft Word / Excel Object Library (Interop) — COM-библиотеки для программного экспорта отчётов в форматы `.docx` и `.xlsx`.
* **Графики:** `System.Windows.Forms.DataVisualization` — построение диаграмм через `WindowsFormsHost` (интеграция Forms в WPF).
* **Контроль версий:** Git + GitHub.

##  Структура базы данных
**Имя базы данных:** `DB_Mulkamonov_Lease`

База данных состоит из 8 взаимосвязанных таблиц:
* `Role` — справочник ролей пользователей (Admin, User).
* `User` — учетные записи пользователей системы.
* `Category` — справочник категорий объектов (Офисное помещение, Склад, Торговая площадь и т.д.).
* `RealEstate` — карточки объектов коммерческой недвижимости.
* `RealEstatePhoto` — таблица для хранения путей к фотографиям объектов (связь один-ко-многим).
* `RentalAgreement` — журнал заключенных договоров аренды.
* `Payment` — история платежей по договорам.
* `Review` — отзывы арендаторов на объекты.

## Реализованный функционал

###  Авторизация и регистрация
* SHA1-хеширование паролей.
* **Защита от подбора пароля:** после 3 неудачных попыток входа форма блокируется и появляется графическая Капча со случайным набором символов.
* **Регистрация:** выбор роли, проверка заполненности всех полей, проверка длины пароля (от 6 символов), подтверждение пароля и валидация на уникальность логина в базе.
* Безопасная смена пароля из системы с проверкой старого пароля.

###  Каталог недвижимости (UserPage)
* Интерактивный просмотр доступных объектов в виде сетки карточек (`ListView` + `WrapPanel`).
* Корректная подгрузка обложек объектов (фотографий) или отображение заглушки-логотипа, если фото отсутствует.
* **Умный фильтр и поиск:** текстовый поиск по названию, фильтрация по категории (через выпадающий список) и сортировка по цене (сначала дешевые / дорогие).
* **Оформление аренды:** возможность указать желаемый срок аренды (в месяцах) с автоматическим расчетом итоговой стоимости договора. Арендованный объект мгновенно скрывается из общего каталога.

###  Панель администратора
* **Управление каталогом (AdminPage / AddRealEstatePage):** добавление новых объектов и редактирование существующих (одна страница работает в двух режимах). Возможность прикрепить фотографию объекта через диалоговое окно (`OpenFileDialog`).
* **Управление договорами (RentalsPage):** просмотр активных договоров. Функция «Завершить аренду», которая переводит договор в статус завершенного и автоматически возвращает объект недвижимости обратно в каталог для пользователей.
* **Каскадное удаление:** при удалении недвижимости или договора из таблицы `DataGrid`, все связанные фото, платежи и отзывы корректно удаляются из базы без нарушения целостности.

### Аналитика и отчёты (ReportPage)
* **Диаграммы:** Столбчатая диаграмма доходов по объектам для выбранного владельца. График стилизован под работу в темной/светлой теме WPF.
* **Экспорт в Microsoft Office:** Программная выгрузка таблиц с доходами в Word и Excel. В Excel-отчете реализовано добавление строки «ОБЩИЙ ИТОГ», выделение цветом и вставка формулы автоматического суммирования `=SUM()`.

###  Интерфейс и UX
* **Две цветовые темы:** Светлая и Темная (графитовая с фирменным синим акцентом). Реализовано через `DynamicResource` и подмену словарей `Dictionary.xaml` "на лету" по кнопке в интерфейсе.
* Стилизация стандартных элементов: переработаны стили для `DataGrid` (цвета строк, шапки таблицы) и выпадающих списков, чтобы они корректно читались в темной теме.
* **Навигация:** Единое окно (Frame), кнопка «Назад», скрывающаяся на стартовых экранах, и «живые» часы в подвале приложения.
